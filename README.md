# GuardianEdge AI

Standalone Next.js demonstration of an Authorized Push Payment (APP) scam-interception journey.

## Run locally

Install Node.js 18.17+ and then run:

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.

## Demo paths

- `/` – senior-citizen persona and attack simulation controls.
- `/transfer` – safe, emergency, and coercion scenario seeders.
- `/verify-context` – plain-language check-in and browser speech alert.
- `/bank-console` – synchronized held-payment investigation console.

The demo controls intentionally simulate browser-observable signals. In a production bank app, call, remote-access, and clipboard intelligence must be supplied by consented mobile/endpoint telemetry services; standard browser pages cannot reliably collect those signals themselves.
